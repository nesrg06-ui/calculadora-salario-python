Calculadora de Salario con Horas Extra (Python).

Este es un proyecto inicial que cree como parte del curso "Python para todos" de la Universidad de Michigan en Coursera.

Qué hace este script?
El programa calcula el pago total de un empleado basándose en las horas trabajadas y una tarifa por hora. Incluye una lógica condicional para pagar las horas extra (más de 40 horas) a una tasa de 1.5 veces la tarifa normal.

Conceptos de Python aplicados:
Entrada de datos del usuario (input) y conversión de tipos (float).

Estructuras condicionales (if / else).

Operadores aritméticos para el cálculo de nómina.
